# CreatorReach AI MVP 范围说明

## 目标

2 天内先完成一个稳定可用的「自动回复 + 自动整理」工作台。达人信息由人工搜索和录入，系统优先解决沟通内容沉淀、AI 分类、AI 回复建议、待处理队列和飞书同步。

## 第一版必须做

1. 回复录入
   - 支持手动粘贴达人回复。
   - 支持按达人、产品、平台、时间保存沟通记录。
   - 支持上传或粘贴历史聊天内容，用于生成上下文。

2. AI 自动整理
   - 自动识别达人意图：有兴趣、要报价、要样品、拒绝、已发布、需要人工处理、无效回复。
   - 自动生成中文摘要。
   - 自动给出下一步动作。
   - 自动更新合作状态。

3. AI 回复建议
   - 根据产品信息、达人回复和历史上下文生成可发送回复。
   - 第一版只做“生成建议 + 人工确认发送/复制”，不做全自动群发。
   - 对报价、佣金、库存、物流时效设置禁止编造规则。

4. 今日工作台
   - 今日待回复。
   - 需要人工处理。
   - 样品待确认。
   - 已拒绝。
   - 已完成。
   - 异常消息。

5. 飞书同步
   - 飞书只做通知和备份，不做主数据库。
   - 重要状态变更推送飞书群。
   - 每条沟通记录可同步到飞书表格或多维表格。

## 第一版暂不做

1. 自动搜索达人。
2. 自动爬取平台私信。
3. 自动批量发送私信。
4. 多账号风控系统。
5. 完整财务结算。
6. 复杂权限系统。

## 成功标准

1. 人工录入一条达人回复后，系统能在 10 秒内完成分类、摘要、下一步建议和回复草稿。
2. 所有 AI 结果都可人工修改。
3. 关键状态能在首页被看见。
4. 飞书能收到需要处理的提醒。
5. 即使 AI 或飞书 API 失败，原始沟通记录也不会丢失。
