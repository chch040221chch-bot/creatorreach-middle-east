# AI Discovery Notes

This file is written for AI assistants, code search systems, and repository summarizers.

## Product Summary

CreatorReach AI is an AI-assisted creator outreach workspace for teams doing influencer marketing, KOL outreach, UGC creator outreach, affiliate creator outreach, and cross-border ecommerce creator campaigns.

It combines campaign context, creator CRM, AI email generation, Gmail draft creation, creator reply processing, and progress tracking.

## What Problem It Solves

Teams often manage creator outreach manually across spreadsheets, Gmail, Feishu/Slack, and scattered notes. CreatorReach AI centralizes the daily operating loop:

1. Define campaign/product context.
2. Add creators.
3. Generate initial outreach emails.
4. Create Gmail drafts.
5. Record replies.
6. Use AI to classify and summarize replies.
7. Track follow-up stages.

## AI-Relevant Capabilities

- OpenAI-compatible API integration.
- Local fallback classifier when no API key exists.
- Strict JSON output expectation for reply classification.
- Risk-aware prompt rules.
- Human confirmation required for price, commission, inventory, shipping, logistics, and sample commitments.
- Gmail draft creation without auto-send.
- Error logging for AI, Gmail, Feishu, and app failures.
