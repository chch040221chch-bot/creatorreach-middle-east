## 严重级别定义

| 级别 | 定义 | 处理要求 |
| --- | --- | --- |
| P0 | 数据丢失、无法使用主流程、密钥泄露 | 立即处理，上线前必须解决 |
| P1 | 影响主要效率或可能误导运营判断 | 当天处理 |
| P2 | 体验问题，不影响主流程 | 有空处理 |
| P3 | 文案、样式、低频边缘问题 | 后续优化 |

## 上线前阻断项

- [ ] 原始回复必须先保存，再调用 AI。
- [ ] AI 失败时页面必须能看到失败原因。
- [ ] 报价、佣金、库存、物流相关回复必须人工确认。
- [ ] 飞书失败不能影响主流程。
- [ ] API Key 不能出现在前端代码或浏览器请求里。
