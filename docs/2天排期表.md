## 状态标签建议

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| new_reply | 收到新回复 | AI 分类 |
| interested | 有兴趣 | 生成合作细节回复 |
| ask_price | 询问报价/佣金 | 进入人工确认 |
| ask_sample | 要样品 | 确认地址和样品规则 |
| rejected | 拒绝合作 | 标记失败，可设置复联时间 |
| posted | 已发布内容 | 进入内容审核 |
| needs_human | 需要人工处理 | 推送飞书 |
| invalid | 无效或看不懂 | 人工复核 |
| done | 本轮处理完成 | 等待下一次回复 |

## 每日验收清单

### Day 1 晚上必须完成

- [ ] 能录入达人回复。
- [ ] 能保存原始沟通记录。
- [ ] AI 能完成分类、摘要、下一步建议。
- [ ] 首页能看到不同状态的待处理数量。
- [ ] API 失败时原始回复不会丢。

### Day 2 晚上必须完成

- [ ] 能生成可编辑回复草稿。
- [ ] 能标记最终发送内容。
- [ ] 关键状态能推送飞书。
- [ ] 有错误日志和重试入口。
- [ ] 完成 10 条测试样本验证。
